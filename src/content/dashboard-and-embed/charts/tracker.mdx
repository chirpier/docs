# Tracker chart

A tracker chart is a threshold-based monitoring view for a hosted event embed. Use it when you need to compare an aggregate against a rule and show pass/fail status.

  eventId="a613d220-34af-45a8-a486-253161e3332f"
  shareToken="a1821391-c7bb-43b2-8d53-d3fd12c682ff"
  minHeight={140}
  state={{
    view: "tracker",
    range: "1d",
    aggregate: "sum",
    tracker: {
      condition: "gte",
      threshold: 5,
    },
  }}
/>

## Additional properties

Configure a tracker embed by setting `state.view` to `tracker` and supplying a tracker rule.

Supported options:

- `state.range`: `1h`, `1d`, `1w`, `1m`
- `state.aggregate`: `sum` or `average`
- `state.header`: `false` to hide the hosted event header
- `state.tracker.condition`: `gt`, `gte`, `lt`, `lte`, `eq`
- `state.tracker.threshold`: numeric threshold to evaluate against
- `theme`: `light`, `dark`, `system`
- `autoResize` or `resizeMode`: control iframe sizing behavior
