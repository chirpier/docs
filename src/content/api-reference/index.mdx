# API Reference

ChirrOp exposes two public HTTP surfaces:

- logs APIs for event logging
- control-plane APIs for reading and managing resources

## Authentication

Send:

```text
Authorization: Bearer <token>
```

The same bearer token works for both logs and control-plane APIs.

## Base URLs

- Logs: `https://logs.chirrop.com`
- Resources: use your ChirrOp app or API host for `/v1.0/events`, `/v1.0/policies`, `/v1.0/alerts`, and `/v1.0/destinations`

## Error shape

Most validation failures return a JSON body like:

```json
{
  "error": "invalid eventID"
}
```

Unauthorized requests return `401` when the bearer token is missing or invalid.
