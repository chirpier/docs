# Common Tasks

All Chirpier SDKs expose helpers around the same resource model.

## Typical helper tasks

- list events
- read one event definition
- read one analytics comparison
- update event metadata
- list policies
- create a policy
- list alerts
- read alert deliveries
- acknowledge, resolve, or archive an alert
- test a destination
- read event rollups
- create, read, list, and update destinations

## When to use SDK helpers

Use the SDK helpers when you want one authenticated client for both:

- Logging event data
- Managing Chirpier resources

This includes the common OpenClaw loop:

- send logs
- list events and resolve `event_id`
- query analytics windows
- create policies
- create destinations
- test destinations and inspect test deliveries

Use raw HTTP when you need language-agnostic integrations, shell automation, or direct infrastructure-level control.

For endpoint-by-endpoint behavior, see [API Reference](/api-reference).
