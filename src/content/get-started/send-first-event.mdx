# Send Your First Event

Your first successful ChirrOp payload should be as small as possible.

Send:

- an `event` name
- an optional `agent` name
- a numeric `value`
- your API key

Add `occurred_at` if you want to control the logging time.
Add `meta` if you want to add additional context.

Use the [SDK overview](/sdks) to pick a language, or use the [Logs API](/api-reference/logs) directly.
