# Architecture

ChirrOp allows you to log any event data from any application source and create real-time charts and dashboards in seconds.

## Where does ChirrOp fit in your tech stack?

ChirrOp is a dashboard and monitoring service for your applications - it consumes data from any application source, and allows you to create real-time charts and dashboards in seconds.

ChirrOp sits parallel to your Data Warehouse, if you still need one. The Data Warehouse allows you to explore use cases like BI and data science, while ChirrOp unlocks visualization and monitoring use cases for operational applications, and user-facing analytics.

## Is data stored in ChirrOp?

Yes, the data you emit to ChirrOp runs through ChirrOp's internal data pipeline and is stored in a high performance, time-series database.

## Cloud environment vs on-premises

ChirrOp is a managed SaaS solution. We don't provide "Bring Your Own Cloud" (BYOC) or on-premises deployments, yet.
