# Overview

[ChirrOp](https://www.chirrop.com) helps you send numeric events, turn them into managed resources, and operate them through dashboards, alerts, analytics windows, and hosted embeds.

The product loop is:

1. Log an event.
2. ChirrOp creates the event definition automatically.
3. Read rollups or analytics.
4. Create policies and handle alerts.
5. Route deliveries to destinations.
6. Share or embed the resulting event views.
