# Python

The [Chirpier SDK for Python](https://github.com/chirpier/chirpier-py) sends flat numeric events to Chirpier with batching and retries.

## Installation

```bash
pip install chirpier
```

## Quick Start

Use `new_client(...)` for new integrations.

```python
from chirpier import new_client, Log

client = new_client(api_key="chp_your_api_key")
client.log(Log(event="task.duration_ms", value=420, agent_id="openclaw.main", meta={"task_name": "email_triage"}))
client.flush()
client.close()
```

## API Reference

### Config

- `api_key`: API key, must start with `chp_`
- `api_endpoint`: full ingestion endpoint override
- `servicer_endpoint`: control-plane endpoint override
- `retries`, `timeout`, `batch_size`, `flush_delay`, `queue_size`, `log_level`: delivery tuning

### Log

Use `Log(...)` with:

- `event`
- `value`
- optional `agent_id`, `occurred_at`, and `meta`

### Common tasks

- `client.list_events()` for event definitions
- `client.create_policy(payload)` for policies
- `client.list_alerts(status)` for alerts
- `client.test_webhook(webhook_id)` for connector tests

See the repo README for the full helper list and migration notes.
