# JavaScript

The [Chirpier SDK for JavaScript](https://github.com/chirpier/chirpier-js) sends flat numeric events to Chirpier with batching and retries.

## Installation

```bash
npm install @chirpier/chirpier-js
```

## Quick Start

Use the instance API for new integrations.

```ts
import { createClient } from "@chirpier/chirpier-js";

const client = createClient({ key: "chp_your_api_key" });

await client.log({
  agent_id: "openclaw.main",
  event: "task.duration_ms",
  value: 420,
  meta: { task_name: "email_triage", result: "success" },
});

await client.flush();
await client.shutdown();
```

## API Reference

### `createClient(config)`

Use `createClient(...)` to create a standalone client without global singleton state.

- `key`: API key, must start with `chp_`
- `apiEndpoint`: full ingestion endpoint override
- `servicerEndpoint`: control-plane endpoint override
- `retries`, `timeout`, `batchSize`, `flushDelay`, `maxQueueSize`: queue and delivery tuning

### `client.log(log)`

```ts
await client.log({
  agent_id: "openclaw.main",
  event: "tool.errors.count",
  value: 1,
  occurred_at: "2026-03-05T14:30:00Z",
  meta: { tool_name: "browser.open" },
});
```

`log` fields:

- `agent_id`: optional producer identifier
- `event`: required event name
- `value`: required numeric value
- `occurred_at`: optional ISO8601 timestamp or `Date`
- `meta`: optional JSON metadata

### Common tasks

- `client.listEvents()` to inspect event definitions
- `client.createPolicy(payload)` to create a policy
- `client.listAlerts(status?)` to review alerts
- `client.testWebhook(webhookID)` to test a connector

See the repo README for the full helper list and connector examples.
