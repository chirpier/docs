# SDK Overview

Chirpier provides lightweight SDKs for JavaScript, Go, and Python.

All three SDKs follow the same model:

- authenticate with an API key that starts with `chp_`
- emit flat numeric events
- flush or shut down cleanly in long-running processes
- optionally manage event definitions, policies, alerts, and connectors with the same bearer token

Pick a language page in this section for install, quick start, and common tasks.
