# Go

The [Chirpier SDK for Go](https://github.com/chirpier/chirpier-go) emits flat numeric events to Chirpier and can also manage event definitions, policies, alerts, and connectors.

## Installation

```bash
go get github.com/chirpier/chirpier-go
```

## Quick Start

Use `NewClient(...)` for standalone clients.

```go
client, err := chirpier.NewClient(chirpier.Options{Key: "chp_your_api_key"})
if err != nil {
    return err
}
defer client.Close(context.Background())

err = client.Log(context.Background(), chirpier.Log{
    AgentID: "openclaw.main",
    Event:   "task.duration_ms",
    Value:   420,
})
if err != nil {
    return err
}

_ = client.Flush(context.Background())
```

## API Reference

### `NewClient(options)`

- `Key`: API key, must start with `chp_`
- `APIEndpoint`: full ingestion endpoint override
- `ServicerEndpoint`: control-plane endpoint override

### `client.Log(ctx, log)`

Use `chirpier.Log` with:

- `AgentID`
- `Event`
- `Value`
- `OccurredAt`
- `Meta`

### Common tasks

- `client.ListEvents(ctx)` for event definitions
- `client.CreatePolicy(ctx, payload)` for policies
- `client.ListAlerts(ctx, status)` for alerts
- `client.TestWebhook(ctx, webhookID)` for connector tests

See the repo README for the full API surface and more complete examples.
