# API

Chirpier exposes an HTTPS API for emitting events and a control-plane API for reading and managing product resources.

## Ingest API

Use the ingest endpoint to send flat numeric events.

Default endpoint:

```text
https://logs.chirpier.co/v1.0/logs
```

Authentication uses a bearer token that starts with `chp_`.

```bash
curl -X POST https://logs.chirpier.co/v1.0/logs \
  -H "Authorization: Bearer chp_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "openclaw.main",
    "event": "task.duration_ms",
    "value": 420,
    "meta": {
      "task_name": "email_triage"
    }
  }'
```

## Event shape

- `event`: required event name
- `value`: required numeric value
- `agent_id`: optional producer identifier
- `occurred_at`: optional timestamp
- `meta`: optional JSON metadata

## Control-plane API

Use the same bearer token with the control-plane API for actions such as:

- listing event definitions
- updating event metadata
- creating policies
- listing and resolving alerts
- testing connectors

If you only need to send data, start with the ingest API or one of the SDKs.
