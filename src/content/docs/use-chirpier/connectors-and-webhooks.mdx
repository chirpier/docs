# Connectors and Webhooks

Connectors let Chirpier deliver alerts to external systems such as Slack or Telegram.

Keep connector docs focused on three things:

- how to create the connector
- how to send a test notification
- how alert deliveries behave when a channel is unavailable

For lightweight SDK references, link to the language-specific examples from the JavaScript, Go, and Python pages instead of duplicating every payload shape here.
