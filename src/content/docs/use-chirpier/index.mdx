# Use Chirpier

Chirpier works best when the docs follow the product flow instead of the repo layout.

The core loop is simple:

1. Emit numeric events from your app or service.
2. See those events in Chirpier as event definitions and rollups.
3. Build charts and dashboards around the events that matter.
4. Create policies that watch those events and trigger alerts.
5. Deliver alerts to the right channel and embed charts where your users need them.

Start with the pages in this section if you want to understand the product model before picking an SDK.
