# Alerts and Policies

Policies describe the condition Chirpier should evaluate for an event, such as whether the hourly sum is greater than a threshold.

Alerts are the concrete records created when a policy triggers.

Use this flow:

1. Pick an event definition.
2. Choose a period such as minute, hour, or day.
3. Choose an aggregate such as sum or average.
4. Define the threshold and severity.
5. Route alert deliveries to a connector.

This keeps policy setup consistent across SDKs, charts, and the web app.
