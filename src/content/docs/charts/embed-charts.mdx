# Embed Charts

Chirpier provides a hosted embed runtime for rendering charts outside the main web app.

Typical flow:

1. Request a short-lived embed token from your backend.
2. Render the hosted runtime in an iframe.
3. Initialize the embed with the chart ID and token.
4. React to ready, resize, and error events in the host app.

Use `@chirpier/charts` for React apps and `@chirpier/embed` for framework-agnostic usage.
