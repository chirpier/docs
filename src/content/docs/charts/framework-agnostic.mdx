# Framework-Agnostic Usage

Use `@chirpier/embed` when you want to mount a chart outside React.

```ts
import { mountChirpierChart } from "@chirpier/embed";

const chart = mountChirpierChart("#chart-root", {
  chartId: "your-chart-id",
  embedToken,
  autoResize: true,
});

chart.updateFilters({ dateRange: "30d" });
chart.updateTheme("light");
```

This is the better fit for vanilla JS, Web Components, or wrappers built for other frameworks.
