# Quick Start

Use this guide to go from account creation to a live chart and first alert.

## Steps

<Steps>

### Create an account

Create an account at [chirpier.co](https://www.chirpier.co/auth).

### Get your API key

Open [Integration Settings](https://www.chirpier.co/teams/integration) and copy the API key you will use to authenticate requests.

### Send your first event

Send a numeric event with:

- your API key
- an `event` name
- a numeric `value`
- optional `agent_id`, `occurred_at`, and `meta`

Use the [SDK overview](/docs/emit/sdk) to pick JavaScript, Go, or Python, or send data with the [API](/docs/emit/api).

### Create a chart

Open the [Charts dashboard](https://www.chirpier.co/teams/charts) and create a chart from the event definition that Chirpier created for your event.

### Create a policy

Create a policy to monitor the event and trigger alerts when the aggregate crosses your threshold.

</Steps>
