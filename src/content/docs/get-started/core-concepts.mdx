# Core Concepts

Chirpier is built around a small set of concepts that map directly to the product workflow.

## Events

An event is the numeric signal you send to Chirpier. It includes an event name, a value, and optional context such as `agent_id`, `occurred_at`, and `meta`.

## Event Definitions

When Chirpier sees a new event name, it creates an event definition that becomes the anchor point for charts, policies, and rollups.

## Charts

Charts visualize an event definition over time using a chart type, a period, an aggregate, and optional filters.

## Policies

Policies describe the rule Chirpier evaluates for an event definition, such as whether the hourly sum is greater than a threshold.

## Alerts

Alerts are created when a policy triggers. Teams can acknowledge, resolve, archive, and inspect delivery attempts from the web app.

## Connectors

Connectors route alert deliveries to external systems such as Slack or Telegram.

## Embed Tokens

Embed tokens are short-lived credentials used by the hosted chart embed runtime.
