# Send Your First Event

Your first successful Chirpier payload should be as small as possible.

Send:

- an `event` name
- a numeric `value`
- your API key

Add `agent_id`, `occurred_at`, and `meta` once the basic flow is working.

Use the [SDK overview](/docs/emit/sdk) to pick a language, or use the [API](/docs/emit/api) directly.
