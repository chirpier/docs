# Overview

[Chirpier](https://www.chirpier.co) helps you emit numeric events, turn them into charts, and trigger alerts when something changes.

The main product flow is:

1. Emit an event with one of the [SDKs](/docs/emit/sdk) or the [API](/docs/emit/api).
2. Inspect the data in the [web app](/docs/web-app).
3. Build a chart from the event definition.
4. Create a policy and route alert deliveries.
5. Embed charts where your users need them.

If you are new to Chirpier, start with [Quick Start](/docs/get-started/quick-start).
