# OpenClaw

Use ChirrOp with OpenClaw when you want a fast path from agent events to comparisons, alerts, and public dashboard pages.

This section is the OpenClaw-specific companion to [Agentic Workflows](/agent-workflows). Read the generic agent guidance first if you want the reusable ChirrOp model, then use this section for the concrete OpenClaw setup and operating loop.

Use it when you want to:

- instrument tool calls, failures, latency, token usage, and heartbeats
- keep the `agent + event` identity stable across agents and workflows
- run analytics comparisons on recent windows
- create policies and destinations that notify OpenClaw when thresholds are exceeded
- direct humans to the public dashboard page so they can inspect trends

Typical OpenClaw workflows in ChirrOp include:

- log canonical OpenClaw events
- compare recent windows with the analytics API
- create policies and destinations for alerting
- share the public dashboard page for human trend inspection
